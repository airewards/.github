# AIRewards

**The AI-native, privacy-focused advertising network for developers and AI power users.**

AIRewards connects ethical advertisers with developers across their daily AI tools through lightweight, non-intrusive, 1-line text-only sponsored messages.

## 🚀 Quick Start for Developers

Install the AIRewards client in 3 seconds:

```bash
npx -y @airewards/cli-wrapper install-extension
```

Or configure your terminal agent wrapper:

```bash
npx -y @airewards/cli-wrapper setup --api-key "air_dev_..."
```

## 🛡️ Privacy & Security Commitments

- **Zero Prompt / Code Inspection:** We never read, transmit, or store your prompts, code, files, or LLM conversations.
- **Data Minimization:** No personal data selling, no tracking cookies, no fingerprint cross-tracking.
- **Fair 50% Revenue Share:** 50% of advertiser gross payments go directly to earners.
